# mind.prime

The reminder app is hosted with GitHub Pages:

https://legend121201.github.io/mind.prime/

## Reminder storage

Reminders are saved in the current browser using local storage. No account or email is required. Reminders do not sync across devices; clearing this browser's site data will remove its saved reminders. The app needs to stay open to show alerts at the reminder time.

You can edit a reminder's title, due time, and subject from its reminder card.
